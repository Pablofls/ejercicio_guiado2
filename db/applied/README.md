# SQL aplicado

Archivos `.sql` que **ya se ejecutaron** en la base de datos de la VM de GCP.

Historial: no se editan ni se vuelven a correr. Si algo hay que corregir, se escribe un archivo nuevo en `db/pending/`.

Ver [Flujo de cambios en la base de datos](../../README.md#flujo-de-cambios-en-la-base-de-datos).

# SQL pendiente

Archivos `.sql` que **todavía no se han ejecutado** en la base de datos de la VM de GCP.

- Nombre: `YYYYMMDD-descripcion-corta.sql`
- Al inicio de cada archivo, un comentario con qué hace y por qué.
- Una vez que el usuario confirma que se ejecutó en la VM, el archivo se mueve a `db/applied/` y se actualizan `schema.sql` y el diagrama de relaciones del README.

Ver [Flujo de cambios en la base de datos](../../README.md#flujo-de-cambios-en-la-base-de-datos).
